# ocr-models

ONNX models for:

* [PP-OCRv5](https://www.paddleocr.ai/main/version3.x/pipeline_usage/OCR.html)
  * PP-LCNet_x1_0_doc_ori_infer（文档图像方向分类模块）
  * UVDoc_infer（文本图像矫正模块）
  * PP-LCNet_x0_25_textline_ori_infer（文本行方向分类模块）
  * PP-LCNet_x1_0_textline_ori_infer（文本行方向分类模块）
  * PP-OCRv5_mobile_det_infer（文本检测模块）
  * PP-OCRv5_server_det_infer（文本检测模块）
  * PP-OCRv5_mobile_rec_infer（文本识别模块）
  * PP-OCRv5_server_rec_infer（文本识别模块）
